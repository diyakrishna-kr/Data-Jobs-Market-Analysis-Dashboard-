# Data Jobs Market Analysis Dashboard

An interactive Streamlit dashboard for exploring job postings by role, employment type, location, salary, skills, and K-Means cluster. Filters let you narrow the dashboard by job category, country, employment type, and experience level.

## Requirements

- Python 3
- The packages listed in [`requirements.txt`](requirements.txt)

## Run on Windows

Open PowerShell in this project folder and create a virtual environment:

```powershell
py -m venv .venv
```

Install the dependencies:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Generate the clustered dataset required by the dashboard:

```powershell
.\.venv\Scripts\python.exe kmeans_clustering.py
```

The clustering script reads `data_jobs_cleaned2.csv` and creates `data_jobs_clustered.csv`. It also opens analysis plots; close those plot windows after reviewing them so the script can finish.

Start the dashboard:

```powershell
.\.venv\Scripts\python.exe -m streamlit run dash.py
```

Streamlit will print a local URL, usually `http://localhost:8501`, to open in your browser.

## Project files

- `dash.py` — Streamlit dashboard
- `kmeans_clustering.py` — creates job clusters and the dashboard dataset
- `data_jobs.csv` — source dataset
- `data_jobs_cleaned2.csv` — cleaned dataset used for clustering
- `requirements.txt` — Python package dependencies
- `*-analysis.py` and `experi-analysis.py` — standalone analysis scripts

`data_jobs_clustered.csv` is generated by `kmeans_clustering.py` and is excluded from Git. Do not commit `.venv`; dependencies can be reinstalled from `requirements.txt`.
